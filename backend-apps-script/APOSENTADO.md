# Backend antigo — aposentado

Este era o backend em Google Apps Script com a planilha como banco, usado enquanto o
app rodava no GitHub Pages.

Foi substituído pela API em `api/`, com Postgres, quando o projeto migrou para o
Vercel. Os arquivos ficam aqui como histórico: o `Codigo.gs` mostra como as mesmas
regras foram escritas para o Apps Script, e pode servir de referência.

A planilha original continua existindo no Drive, mas **não está mais ligada ao app**.
Ela guarda os dados até a data da migração e não recebe nada novo.

Nada aqui precisa rodar. Se você está procurando como publicar o app, veja o
`README.md` na raiz.
